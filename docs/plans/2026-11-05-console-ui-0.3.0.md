# Console UI 0.3.0 — the tower console on @savvagent/console-ui 0.3.0

**Goal:** the console runs on `@savvagent/console-ui@0.3.0` (exact pin) and uses its new API:
no locale cast, card titles as headings without nesting, and the build version as plain footer text.

it exactly.
